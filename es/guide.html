Cómo Utilizar Dark Gateway OS

Guía ilustrada completa sobre el primer arranque, configuración de red, proxy en cascada, cortafuegos granular y aplicaciones integradas.

⚡ NAVEGACIÓN RÁPIDA POR SECCIONES:
1. Arranque y Tor 2. Adaptadores de Red 3. Asistente Proxy 4. Centro de Firewall 5. Navegador y Telegram 6. Borrado de Rastros 7. Actualizaciones del SO 8. Monitorización HUD
Paso 1: Aislamiento en Arranque y Conexión Tor 01
PASO 1

Paso 1: Primer Arranque y Configuración de Tor (Boot Isolation)

Al arrancar la red está congelada (DisableNetwork 1) para prevenir fugas accidentales. Elija Tor directo o pegue un puente WebTunnel / obfs4 en Tor Connection Setup y haga clic en [Connect].

📋 Modos de Conexión:
  • • Direct Tor: Conexión directa a la red Tor (adecuada para redes sin censura).
  • • Configure custom bridge: Uso de puentes HTTPS webtunnel u obfs4 para eludir bloqueos DPI estrictos.
Paso 2: Configurador Gráfico de Red 02
PASO 2

Paso 2: Configuración de Adaptadores de Red (Network GUI)

Configure WAN eth0 (DHCP o IP Estática) y el gateway LAN eth1 (10.152.152.10) con servidor DHCP mediante Cmd+n.

Adaptador 1: eth0 (WAN Externa / Internet)
Configuración automática DHCP o IP estática y puerta de enlace manual.
Adaptador 2: eth1 (Puerta de Enlace LAN)
Gateway 10.152.152.10, máscara 255.255.192.0, pool DHCP integrado para estaciones de trabajo conectadas.
Configuración de Adaptadores de Red (Cmd+n)
Paso 3: Asistente de Proxies Multiprotocolo (Puerto 1080) 03
PASO 3

Paso 3: Cadenas de Proxy Multiprotocolo (Proxy Setup Wizard)

Importe enlaces vless:// Reality o ss:// Shadowsocks en Proxy Wizard (Cmd+p) para salir a través de nodos privados de alta velocidad.

⚠️ Estado del Protocolo Trojan:
El protocolo Trojan se encuentra actualmente en desarrollo y aún no está soportado en Proxy Wizard. El soporte está programado para próximas versiones.
Asistente Proxy Setup Wizard (Cmd+p)
Paso 4: Centro de Control de Firewall Granular nftables 04
PASO 4

Paso 4: Firewall Granular (Firewall & Security Control Center)

Controle 8 módulos nftables (Cmd+f) para bloquear o permitir tráfico en Chromium, Telegram, actualizaciones o activar el Killswitch.

1. Navegador Web Chromium
2. Cliente Telegram Desktop
3. Sing-Box SOCKS (Puerto 1080)
4. Servidor Web Onion (8080)
5. Enrutamiento LAN (eth1)
6. Actualizaciones Sistema y Tor
7. Administración SSH (22)
8. Killswitch de Pánico WAN
Centro de Control de Firewall (Cmd+f)

Paso 8: Monitorización del Sistema y Utilidades 08
PASO 8

Paso 8: Monitorización del Sistema y Utilidades Integradas

Monitorización en vivo con Conky HUD, Nyx Tor Monitor (Cmd+m), Midnight Commander, Terminal Bash, Mousepad y control de audio.

Conky — Panel HUD en Tiempo Real

Barra lateral HUD: carga de CPU/RAM, tráfico eth0/eth1, puertos de escucha activos.

Nyx — Monitor de Red Tor

Monitor interactivo de Tor (Cmd+m) con gráficos de ancho de banda y visor de circuitos.

Midnight Commander (mc)

Gestor de archivos de doble panel clásico en paleta Dark Pastels.

Consola de Terminal Bash

Terminal minimalista con integración de atajos de teclado del escritorio.

Editor de Texto Mousepad

Editor de texto GTK3 rápido y limpio para archivos de configuración y claves.

Control de Audio y Volumen

Widget nativo en C/GTK3 para control de volumen y micrófono.
