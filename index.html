⚡ CORE CAPABILITIES & ARCHITECTURE

▪ Multi-Protocol Proxy Egress

Seamlessly chains onion circuits into private VLESS Reality (XTLS Vision) or Shadowsocks nodes (Trojan in active development). Eliminates Cloudflare/Google captchas.

▪ Zero-Leak Boot Isolation

Network starts frozen (DisableNetwork 1). Connection opens only after explicit routing selection in Tor Connection Setup.

▪ Granular nftables Firewall

Controls network access on kernel-socket GID level per application with instant active socket termination (ss -K).

▪ Pure C (GTK3) Native Stack

All GUI utilities are written in pure C without Python/Bash overhead. Millisecond startup time and ultra-low memory consumption (~600 MB RAM).

▪ Automated Anti-Forensics

Wipe Privacy Traces tool and wipe-traces.service automatically purge browser cache, sessions, command history, and temporary logs on shutdown.

▪ Hardened Privacy Applications

Preconfigured Ungoogled Chromium with anti-fingerprinting and isolated Telegram Desktop with auto-proxy persistence.

System Requirements & Virtualization

⚡ MINIMUM SYSTEM REQUIREMENTS
  • • Processor: 1–2 vCPU (x86_64 with VT-x/AMD-V)
  • • RAM: 2 GB RAM (~600 MB idle consumption)
  • • Storage: 15 GB free disk space
  • • Network: 2 virtual NICs (WAN NAT + LAN Host-Only)
🚀 RECOMMENDED SPECIFICATIONS
  • • Processor: 2–4 vCPU
