الخطوة 1: عزل الإقلاع والاتصال بشبكة Tor 01
الخطوة 1

الخطوة 1: الإقلاع الأول وإعداد شبكة Tor (Boot Isolation)

عند بدء التشغيل، يتم تجميد الشبكة تلقائيًا (DisableNetwork 1) لمنع أي تسريب. اختر الاتصال المباشر أو ألصق جسر WebTunnel / obfs4 في نافذة Tor Connection Setup واضغط [Connect].

📋 أوضاع الاتصال المتاحة:
  • • Direct Tor: اتصال مباشر بشبكة Tor (مناسب للشبكات التي لا تفرض رقابة).
  • • Configure custom bridge: استخدام جسور HTTPS المشفرة مثل webtunnel أو obfs4 لتجاوز فلاتر DPI الصارمة.
الخطوة 2: الواجهة الرسومية لمحولات الشبكة 02
الخطوة 2

الخطوة 2: إعداد بطاقات الشبكة (Network GUI)

اضغط الاختصار Cmd+n لضبط بطاقة WAN الخارجية eth0 (تلقائي DHCP أو IP ثابت) وبوابة LAN الداخلية eth1 (العنوان 10.152.152.10 مع خادم DHCP مدمج).

المحول 1: eth0 (الإنترنت الخارجي / WAN)
الحصول التلقائي عبر DHCP أو إدخال عنوان IP الثابت والبوابة الافتراضية يدويًا.
المحول 2: eth1 (البوابة الداخلية / LAN)
البوابة 10.152.152.10، وقناع الشبكة 255.255.192.0، ونطاق DHCP المدمج لتوزيع العناوين على محطات العمل المتصلة.
أداة إعداد بطاقات الشبكة (Cmd+n)
الخطوة 3: معالج البروكسي متعدد البروتوكولات (المنفذ 1080) 03
الخطوة 3

الخطوة 3: الربط المتسلسل بالبروكسي (Proxy Setup Wizard)

استورد روابط vless:// Reality أو ss:// Shadowsocks عبر معالج البروكسي (Cmd+p) للخروج عبر عقد خاصة فائقة السرعة.

⚠️ ملاحظة حول حالة بروتوكول Trojan:
بروتوكول Trojan قيد التطوير والاختبار حاليًا وغير مدعوم في Proxy Wizard في هذا الإصدار، وسيتم إتاحته في التحديثات القادمة.
معالج إعداد البروكسي Proxy Wizard (Cmd+p)
الخطوة 4: مركز التحكم الدقيق بجدار الحماية nftables 04
الخطوة 4

الخطوة 4: جدار الحماية التفصيلي (Firewall Control Center)

تحكم في 8 وحدات مستقلة في nftables بالضغط على Cmd+f للسماح أو حظر حركة المرور لـ Chromium و Telegram والتحديثات، أو تفعيل مفتاح الطوارئ Killswitch.

1. متصفح الويب Chromium
2. تطبيق Telegram Desktop
3. منفذ Sing-Box SOCKS (1080)
4. خادم الويب Onion (8080)
5. توجيه شبكة العميل LAN (eth1)
6. تحديثات النظام وأمان Tor
7. الإدارة عن بُعد عبر SSH (22)
8. مفتاح قطع الطوارئ WAN Killswitch
مركز التحكم بجدار الحماية والأمان (Cmd+f)
الخطوة 5: متصفح وتطبيق مراسلة محصنان ضد التتبع 05
الخطوة 5

الخطوة 5: تصفح الويب الآمن والمراسلة الخاصة

تم إعداد متصفح Chromium مسبقًا عبر البروكسي SOCKS5 127.0.0.1:1080 بدون أي تسريب لـ WebRTC أو DNS. يعمل Telegram في مجموعة معزولة مع حفظ دائم للبروكسي.

🌐 Ungoogled Chromium

اختبار BrowserLeaks: 0 تسريب لـ DNS/WebRTC، عنوان IP مجهول كليًا.

💬 Telegram Desktop

ملف تعريف بروكسي SOCKS5 الدائم جاهز: متصل بالإنترنت.
الخطوة 6: أداة مسح الآثار الجنائية الرقمية 06
الخطوة 6

الخطوة 6: المسح الشامل لآثار الجلسة (Wipe Privacy Traces)

امسح على الفور سجل التصفح، والملفات المؤقتة، وجلسات Telegram، وسجلات Bash بنقرة واحدة عبر الاختصار Cmd+Shift+k (يتم تنفيذه تلقائيًا عند إيقاف التشغيل).

✓ ذاكرة التخزين المؤقت، وملفات تعريف الارتباط، وسجل تصفح Chromium
✓ جلسات تسجيل الدخول والملفات المحملة في Telegram Desktop
✓ بيانات اعتماد وإعدادات بروكسي VLESS و Shadowsocks المحفوظة
✓ سجل أوامر الطرفية Bash وسجلات النظام المؤقتة
أداة مسح الخصوصية Wipe Privacy Traces (Cmd+Shift+k)

الخطوة 8: مراقبة النظام والأدوات المدمجة 08
الخطوة 8

الخطوة 8: مراقبة الأداء والأدوات المساعدة المدمجة

مراقبة حية عبر Conky HUD، ومراقب Tor التفاعلي Nyx (Cmd+m)، ومدير الملفات Midnight Commander، والطرفية Bash، ومحرر Mousepad، وأداة التحكم بالصوت.

Conky — شاشة القياس في الوقت الفعلي

شريط جانبي لمراقبة استهلاك المعالج والذاكرة، وحركة البيانات على eth0/eth1، والمنافذ المفتوحة.

Nyx — مراقب شبكة Tor

أداة تفاعلية لمراقبة شبكة Tor (Cmd+m) مع رسوم بيانية حية لحجم البيانات ومسارات الدوائر.

Midnight Commander (mc)

مدير ملفات كلاسيكي مزدوج اللوحات بمظهر Dark Pastels الأنيق.

وحدة التحكم الطرفية Bash

طرفية سريعة وخفيفة مع تكامل كامل لاختصارات سطح المكتب.

محرر النصوص Mousepad

محرر نصوص GTK3 سريع ونظيف ومثالي لتعديل ملفات التكوين والمفاتيح.

التحكم في الصوت والميكروفون

أداة C/GTK3 أصلية لضبط مستوى الصوت وحساسية الميكروفون بسرعة.
