Step 1: Tor Boot Isolation & Initial Connection 01
STEP 1

Step 1: Initial Boot & Tor Setup (Boot Isolation)

On system boot, network is paused (DisableNetwork 1) to prevent accidental data leaks. Choose Direct Tor or paste a WebTunnel / obfs4 bridge string in Tor Connection Setup, then click [Connect].

📋 Connection Modes:
  • • Direct Tor: Direct connection to the Tor network (suitable for uncensored networks).
  • • Configure custom bridge: Use webtunnel or obfs4 bridges to bypass strict DPI censorship.
Step 2: Network Adapters Configuration GUI 02
STEP 2

Step 2: Network Adapters Configuration (Network GUI)

Configure WAN eth0 (DHCP/Static IP) and internal LAN eth1 gateway (10.152.152.10) with DHCP server via Cmd+n.

Adapter 1: eth0 (External WAN / Internet)
DHCP Automatic or Manual Static IP and Gateway configuration.
Adapter 2: eth1 (Internal LAN Gateway)
Gateway 10.152.152.10, Subnet 255.255.192.0, integrated DHCP pool for connected workstations.
Network Adapters Configuration (Cmd+n)
