步骤 1：开机网络隔离与 Tor 连接配置 01
步骤 1

步骤 1：首次开机与 Tor 网关连接 (Boot Isolation)

开机时网络处于冻结状态（DisableNetwork 1）以防止意外数据泄漏。在 Tor Connection Setup 窗口中选择直连或粘贴 WebTunnel / obfs4 网桥，然后点击 [Connect]。

📋 连接模式选择：
  • • Direct Tor： 直接连接到 Tor 网络（适用于无审查的常规网络环境）。
  • • Configure custom bridge： 使用 webtunnel 或 obfs4 HTTPS 混淆网桥突破严苛 DPI 封锁。
步骤 2：图形化网络适配器配置器 02
步骤 2

步骤 2：配置网络适配器 (Network GUI)

使用快捷键 Cmd+n 配置外部 WAN eth0（DHCP 或静态 IP）以及内置 DHCP 服务的内部 LAN eth1 网关（10.152.152.10）。

适配器 1: eth0 (外部 WAN / 互联网)
自动通过 DHCP 获取 IP，或手动指定静态 IP 和网关。
适配器 2: eth1 (内部 LAN 网关)
网关 10.152.152.10，子网掩码 255.255.192.0，集成 DHCP 池为连接的工作站分配 IP。
网络适配器配置工具 (Cmd+n)
步骤 3：多协议代理配置向导 (端口 1080) 03
步骤 3

步骤 3：多协议代理级联 (Proxy Setup Wizard)

在 Proxy Wizard (Cmd+p) 中导入 vless:// Reality 或 ss:// Shadowsocks 链接，通过高速私有节点出口访问网络。

⚠️ 关于 Trojan 协议的支持状态说明：
Trojan 协议目前正在积极开发与测试中，暂未在 Proxy Wizard 中启用。我们计划在后续版本中正式推出支持。
代理配置向导 Proxy Wizard (Cmd+p)
步骤 4：细粒度 nftables 防火墙控制中心 04
步骤 4

步骤 4：细粒度防火墙管理 (Firewall Control Center)

按 Cmd+f 控制 8 个独立的 nftables 模块，允许或阻止 Chromium、Telegram、系统更新的流量，或一键激活 Killswitch。

1. Chromium 网页浏览器
2. Telegram Desktop 桌面客户端
3. Sing-Box SOCKS (端口 1080)
4. Onion Web 网页服务器 (端口 8080)
5. 客户端 LAN 路由 (eth1)
6. 系统与 Tor 安全更新
7. SSH 远程管理 (端口 22)
8. WAN 紧急断网 Killswitch
防火墙与安全控制中心 (Cmd+f)

步骤 6：会话痕迹一键粉碎 (Wipe Privacy Traces)

按 Cmd+Shift+k 快捷键即可在 1 秒内彻底清除浏览器历史、Cookies、Telegram 会话和 Bash 记录（关机时亦会自动执行）。

✓ Chromium 浏览器缓存、Cookies 及浏览记录
✓ Telegram Desktop 登录会话与已下载文件
✓ 保存的 VLESS 及 Shadowsocks 代理配置信息
✓ 终端 Bash 历史命令与系统临时日志
隐私痕迹清理工具 Wipe Privacy Traces (Cmd+Shift+k)
