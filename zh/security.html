🛡️ 安全架构与隐私保护政策

Dark Gateway OS 安全体系架构

Dark Gateway OS 围绕最小化攻击面原则、Linux 内核级严格流隔离以及完全排除遥测服务的标准设计构建。

01 零遥测隐私保证

彻底杜绝数据收集与追踪

系统内绝对不含任何后台追踪器、分析遥测守护进程、崩溃报告发送程序或向开发者服务器的外部同步服务。

02 开机网络完全暂停

开机防漏物理级隔离 (Airgap)

Tor 守护进程在开机时默认拦截所有出站流量（DisableNetwork 1），直到用户显式选择路由模式，杜绝开机期间明文数据包逃逸。

03 内核套接字级隔离

基于 GID 的套接字白名单控制

nftables 防火墙规则严格绑定到内核进程组 ID（GID），未经显式授权的应用程序无法向网络发送任何数据包。

04 关机数据自动粉碎

自动化反取证清理

wipe-traces.service 在系统进入关机流程（shutdown.target）时触发，安全粉碎浏览器缓存、Telegram 会话及终端命令历史记录。

威胁模型与防御策略

  • • 防范运营商 (ISP) 嗅探： 100% 的出站流量均封装于 WebTunnel HTTPS 隧道或 Tor v3 洋葱加密链路中。
  • • 防范深度数据包检测 (DPI)： 搭载 XTLS Vision 的 VLESS Reality 将流量精确伪装成全球主流 CDN 的合法 TLS 流量，使其与普通网页浏览完全无法区分。
  • • 防范 DNS 与 WebRTC 泄漏： 内部 DNS 解析器强制将所有查询重定向至 10.152.152.10:5300（Tor 内部解析端口），完全绕过运营商 DNS 服务器。
