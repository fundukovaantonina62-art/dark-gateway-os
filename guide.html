Step 1: Tor Boot Isolation & Initial Connection 01
STEP 1

Step 1: First Boot & Tor Connection (Boot Isolation)

On system boot, traffic is frozen (DisableNetwork 1) to prevent accidental leaks. In the Tor Connection Setup window, choose Direct Tor or paste a WebTunnel / obfs4 bridge line and click [Connect].

📋 Connection Modes:
  • • Direct Tor: Direct connection to the Tor network (suitable for networks without censorship).
  • • Configure custom bridge: Use webtunnel or obfs4 HTTPS bridges to bypass strict DPI filters.
Step 2: Network Adapters Configuration GUI 02
STEP 2

Step 2: Network Adapters Configuration (Network GUI)

Configure external WAN eth0 (DHCP or Static IP) and internal LAN gateway eth1 (10.152.152.10) with DHCP server via Cmd+n.

Adapter 1: eth0 (External WAN / Internet)
Automatic DHCP or manual static IP and gateway configuration.
Adapter 2: eth1 (Internal LAN Gateway)
Gateway 10.152.152.10, subnet 255.255.192.0, integrated DHCP pool for connected workstations.
Network Adapters Configuration (Cmd+n)

Step 3: Multi-Protocol Proxy Chains (Proxy Setup Wizard)
