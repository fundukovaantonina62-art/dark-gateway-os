Как пользоваться Dark Gateway OS

Полная иллюстрированная инструкция по запуску, первоначальной настройке сети, управлению прокси-цепочками, работе с гранулярным фаерволом и встроенными приложениями.

⚡ Быстрая навигация:
1. First Boot & Tor Setup 2. Network Adapters GUI 3. Proxy Wizard (:1080) 4. Firewall Control Center 5. Chromium & Telegram 6. Wipe Privacy Traces 7. Update Manager 8. System Monitoring
Step 1: Tor Boot Isolation
STEP 1

Раздел 1: Первый запуск и подключение Tor (Tor Boot Isolation)

При включении сеть заморожена (DisableNetwork 1). В окне Tor Connection Setup выберите Direct Tor или вставьте строку моста WebTunnel/obfs4 и нажмите [Connect].

Step 2: Network Adapters
STEP 2

Раздел 2: Конфигурация сетевых адаптеров (Network Adapters GUI)

Настройте внешний адаптер WAN eth0 (DHCP/Static IP) и внутренний шлюз LAN eth1 (10.152.152.10) с DHCP-сервером через Cmd+n.

  • Adapter 1: eth0 (External WAN): DHCP Automatic or Manual Static IP.
  • Adapter 2: eth1 (Internal LAN): Gateway IP 10.152.152.10, Subnet 255.255.192.0, DHCP Pool 10.152.152.50-150.
Network Adapters Configuration (Cmd+n)
Step 3: Proxy Setup Wizard
STEP 3

Раздел 3: Каскадные прокси-цепочки (Proxy Setup Wizard)

Импортируйте ключи vless:// Reality или ss:// Shadowsocks в Proxy Wizard (Cmd+p) для выхода через быстрые приватные ноды.

⚠️ Note: Trojan protocol is currently in development and not yet supported in Proxy Wizard.
Proxy Setup Wizard (Cmd+p)
Step 4: Firewall Control Center
STEP 4

Раздел 4: Гранулярный фаервол (Firewall & Security Control Center)

Управляйте 8 модулями nftables (Cmd+f) для блокировки/разрешения сети для Chromium, Telegram, апдейтов или включения Panic Killswitch.

  • 1. Chromium Web Browser: Toggle Tor & Sing-Box traffic.
  • 2. Telegram Desktop: Isolate Telegram socket egress.
  • 3. Sing-Box SOCKS Proxy (1080): Enable/disable proxy dispatcher.
  • 4. Onion Web Server (8080): Local hidden service web port.
  • 5. LAN Workstation Routing (eth1): Route client VM traffic.
  • 6. System & Tor Updates: Allow APT / Tor package fetching.
  • 7. SSH Management (Port 22): Incoming admin access.
  • 8. WAN Panic Killswitch: Instant hardware packet isolation.
Firewall & Security Control Center (Cmd+f)

STEP 8

Interactive circuit monitor (Cmd+m) with live bandwidth graphs and Tor daemon events.

Classic dual-pane terminal file manager with Dark Pastels theme.

Lightweight shell with optimized font rendering and shortcut integration.

Mousepad Text Editor

Distraction-free GTK3 notepad for editing notes, keys, and configurations.

Volume & Audio Control

Native GTK3 audio manager with instant microphone mute toggles.
