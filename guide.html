Раздел 1: Первый запуск и подключение Tor (Tor Boot Isolation)
ШАГ 1

Инициализация и запуск сети Tor

Для защиты от случайных утечек трафика в Dark Gateway OS реализован механизм Tor Boot Pause. При включении виртуальной машины сеть находится в замороженном состоянии (DisableNetwork 1).

Сразу после входа в систему автоматически открывается окно Tor Connection Setup:

📋 Как выполнить подключение:

  1. Прямое подключение (Direct Tor network connection): выберите этот пункт, если в вашей сети узлы Tor не заблокированы провайдером.
  2. Подключение через мосты (Configure custom bridge): выберите этот пункт и вставьте строку моста WebTunnel (webtunnel 192.0.2.1:443 ... url=https://...) или obfs4 (obfs4 192.0.2.2:443 ...), если прямой доступ заблокирован.
  3. Нажмите кнопку [Connect]. Шлюз применит настройки и установит защищенный 3-хоповый канал.
💡 Подсказка: Статус соединения и процент построения цепочки всегда отображаются в правой панели мониторинга Conky HUD.
Раздел 2: Конфигурация сетевых адаптеров (Network Adapters GUI)
ШАГ 2

Настройка внешнего (WAN) и внутреннего (LAN) адаптеров

Приложение Network Adapters Configuration (горячая клавиша Cmd+n или через системное меню) позволяет гибко перенастраивать сетевые интерфейсы без необходимости редактировать текстовые конфиги.

Адаптер 1: eth0 (Внешняя сеть WAN / NAT)

  • DHCP (Automatic IP): автоматическое получение IP-адреса и шлюза от вашего роутера или гипервизора.
  • Static IP (Manual): ручной ввод IP-адреса, маски подсети и шлюза по умолчанию (например, 172.16.103.150 / 255.255.255.0 / 172.16.103.2).

Адаптер 2: eth1 (Внутренняя сеть LAN для Workstation)

  • Gateway IP: 10.152.152.10 (Маска: 255.255.192.0).
  • DHCP Server: включение встроенного DHCP-сервера для автоматической раздачи IP подключенным рабочим станциям (пул: 10.152.152.50 - 10.152.152.150).
Network Adapters Configuration — атомарное управление eth0 и eth1
Раздел 3: Каскадные прокси-цепочки (Proxy Setup Wizard)
ШАГ 3

Маршрутизация через Sing-Box (Порт 1080)

Для преодоления цензуры и обхода блокировок Cloudflare/Google Captcha в Dark Gateway OS интегрирован диспетчер Sing-Box, слушающий локальный порт 127.0.0.1:1080.

📋 Инструкция по настройке:

  1. Откройте Proxy Setup Wizard нажатием Cmd+p или через меню Applications ➔ Proxy Setup Wizard.
  2. Скопируйте ключ вашего прокси-сервера (поддерживаются форматы vless://... с Reality/XTLS Vision и ss://... Shadowsocks).
  3. Вставьте ключ в текстовое поле и нажмите [Apply & Connect].
  4. Для возврата в режим чистого Tor нажмите [Disconnect / Direct Tor].
⚠️ Примечание: Протокол Trojan на данный момент не поддерживается в мастере Proxy Wizard. Поддержка запланирована в следующих релизах.
Proxy Setup Wizard — быстрый импорт vless:// и ss:// ключей
Раздел 4: Гранулярный фаервол (Firewall & Security Control Center)
ШАГ 4

Селективная изоляция приложений на уровне ядра

Firewall Control Center (горячая клавиша Cmd+f) — нативный C-интерфейс к фаерволу nftables, фильтрующий сокеты программ по специальным системным GID.

Доступные модули контроля (8/8):

  • 1. Chromium Web Browser: блокировка/разрешение сетевой активности браузера.
  • 2. Telegram Desktop: изоляция трафика мессенджера Telegram.
  • 3. Sing-Box SOCKS Proxy (1080): управление портом каскадного прокси.
  • 4. Onion Web Server (8080): переключатель доступа к локальному скрытому веб-серверу.
  • 5. LAN Workstation Routing (eth1): пропуск трафика клиентских виртуалок через Tor.
  • 6. System & Tor Updates: разрешение загрузки обновлений Debian и Tor.
  • 7. SSH Management (Port 22): включение/отключение порта удаленного доступа.
  • 8. WAN Panic Killswitch: аппаратный аварийный рубильник — мгновенный сброс всех пакетов на eth0.
Firewall & Security Control Center — управление 8 модулями изоляции
Раздел 5: Приватный веб-серфинг и мессенджер
ШАГ 5

Ungoogled Chromium и Telegram Desktop

🌐 Ungoogled Chromium

Полностью дегуглифицированный Chromium с отключенной телеметрией. Автоматически настроен на прокси-порт 127.0.0.1:1080, снабжен защитой от конфликтов SQLite-профилей и проверкой утечек WebRTC/DNS.

Проверка на BrowserLeaks: 0 утечек IP/DNS, анонимный выходной узел.

💬 Telegram Desktop

Официальный клиент Telegram, работающий в изолированной группе безопасности. Встроенные преднастроенные профили прокси SOCKS5 (127.0.0.1:1080 и 127.0.0.1:9050) сохраняются между сессиями.

Окно настроек прокси в Telegram Desktop: статус Online.
Раздел 6: Уничтожение следов сессии (Wipe Privacy Traces)
ШАГ 6

Анти-криминалистическая зачистка (Anti-Forensics)

Утилита Wipe Privacy Traces (Cmd+Shift+k) предназначена для моментального безвозвратного удаления цифровых следов:

  • История посещений, кэш и cookies браузера Chromium.
  • Активные сессии и временные медиафайлы Telegram.
  • Сохраненные прокси-ключи и конфигурации VLESS/Shadowsocks.
  • История команд оболочки Bash (.bash_history) и временные системные логи.

При нажатии кнопки [Wipe Everything] очистка выполняется в фоновом режиме за доли секунды. Также зачистка автоматически вызывается службой wipe-traces.service при штатном выключении ОС.

Wipe Privacy Traces — стирание следов активности в 1 клик
Раздел 7: Безопасное обновление (System & Tor Update Manager)
ШАГ 7

Обновление пакетов и аварийное восстановление

System & Tor Update Manager обеспечивает неразрушающее обновление операционной системы:

  • Standard Update: загрузка пакетов безопасности Debian и бинарников Tor через защищенные репозитории с автобэкапом настроек AwesomeWM и тем оформления.
  • Emergency Recovery: восстановление сетевых конфигов и Tor в случае сбоя внешних репозиториев.
  • Health & Repair: автоматический вызов скрипта аудита системы health-check.
System & Tor Update Manager — безопасный апдейт компонентов
Раздел 8: Системный мониторинг и встроенные утилиты
ШАГ 8

Обзор мониторов и вспомогательного софта

Conky Real-time HUD

Живой сайдбар на рабочем столе: нагрузка CPU/RAM, пропускная способность eth0/eth1, статус демонов Tor/Sing-Box и список активных портов.

Nyx — Tor Network Monitor

Консольный монитор сети Tor (запуск по Cmd+m): график пропускной способности, детальный просмотр цепочек (circuits) и журнал событий.

Midnight Commander (mc)

Классический двухпанельный менеджер файлов для быстрой и безопасной навигации по файловой системе без запуска тяжелых графических оболочек.

Terminal Console (Bash)

Минималистичный терминал с цветовой палитрой Dark Pastels, оптимизированным шеллом Bash и быстрым доступом к утилитам командной строки.

Mousepad Text Editor

Быстрый и чистый текстовый редактор для редактирования заметок, ключей и конфигурационных файлов.

Volume & Audio Control

Нативный C/GTK3 регулятор громкости звука и уровня чувствительности микрофона с поддержкой мгновенного отключения (Mute).
