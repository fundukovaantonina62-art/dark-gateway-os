Dark Gateway OS のセキュリティ設計体系

Dark Gateway OS は、攻撃面の最小化原則、Linux カーネルレベルでの厳格な通信ストリーム分離、および完全なゼロテレメトリ保証に基づいて構築されています。

01 ゼロテレメトリ保証

データ収集と追跡の完全排除

システム内にはバックグラウンドの解析デーモン、クラッシュレポート送信機能、開発者サーバへの外部同期プログラムは一切存在しません。

02 起動時ネットワーク完全遮断

起動時防漏エアギャップ

Tor デーモンは起動時にすべての外部通信をデフォルトで遮断（DisableNetwork 1）し、ユーザーがルーティング方法を明示的に選択するまで、平文パケットの漏洩を物理的に防ぎます。

03 カーネルソケットレベルの隔離

GID ソケットホワイトリスト制御

nftables ファイアウォールルールはカーネルのプロセスグループID（GID）に厳格に紐付けられており、明示的な許可のないアプリケーションはパケットを一切送信できません。

04 シャットダウン時自動データ完全消去

自動アンチフォレンジック

wipe-traces.service がシステムの終了処理（shutdown.target）時に起動し、ブラウザキャッシュ、Telegram セッション、シェル履歴を安全に粉砕消去します。

脅威モデルと防御方針

  • • プロバイダ (ISP) による盗聴防御: すべてのアウトバウンド通信は WebTunnel HTTPS トンネルまたは Tor v3 Onion 回路内に100%カプセル化されます。
  • • DPI (深層パケット検査) 防御: XTLS Vision を搭載した VLESS Reality により、正規の大手CDNのTLS証明書通信を精巧に擬態し、通常のWebトラフィックと区別不能にします。
  • • DNS および WebRTC リーク防御: 内部DNSリゾルバがすべての名前解決リクエストを 10.152.152.10:5300（Tor内部名前解決ポート）へ強制転送し、ISPのDNSを完全にバイパスします。
