⚡ システム機能とアーキテクチャの柱

▪ マルチプロトコルプロキシ出口

Tor回路をプライベートな VLESS Reality (XTLS Vision) または Shadowsocks ノードに連結（Trojanは開発中）。Cloudflare/Google Captchaを回避します。

▪ ゼロリーク起動時隔離

起動時はネットワークが完全停止（DisableNetwork 1）。Tor Connection Setup で明示的に選択するまで通信を遮断します。

▪ きめ細かな nftables ファイアウォール

カーネルソケットGIDに基づいてアプリ単位でネットワークを制御し、アクティブな接続を即座にリセット（ss -K）。

▪ Pure C (GTK3) ネイティブスタック

すべてのGUIツールをネイティブC言語で開発。Python/Bashのオーバーヘッドがなく、ミリ秒起動と約600MBの低メモリ消費を実現。

▪ 自動アンチフォレンジック

Wipe Privacy Traces と wipe-traces.service により、シャットダウン時にブラウザキャッシュやログを自動消去します。

▪ プライバシー強化アプリ

指紋追跡防止付き Ungoogled Chromium と、プロキシ設定が永続化される隔離 Telegram Desktop を搭載。

動作環境と仮想化プラットフォーム

⚡ 最小システム要件
  • • CPU: 1–2 vCPU (VT-x/AMD-V 対応 x86_64)
  • • メモリ: 2 GB RAM (アイドル時消費約 600 MB)
  • • ディスク: 15 GB 以上の空き容量
  • • NIC: 仮想NIC 2枚 (WAN NAT + LAN Host-Only)
🚀 推奨スペック
  • • CPU: 2–4 vCPU
  • • メモリ: 4 GB RAM
  • • ディスク: 30 GB NVMe / SSD
  • • NIC: ギガビット WAN ブリッジ + 隔離 LAN vSwitch
VMware向けに開発・完全検証済み

VMware Fusion および VMware Workstation に最適化されています。OVAインポート後エラーなく即起動。

VirtualBoxの互換性について

Oracle VirtualBoxでの動作は可能ですが、公式テストは未実施です。仮想ネットワークの設定は手動で行う必要があります。
